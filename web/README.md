# Web viewer — interactive trace inspector (MapLibre GL JS)

An interactive single-page map for inspecting sample device traces and
spotting data problems (GPS spikes, shared `maid` IDs) — instead of relying
on static Python plots.

## Files
- `index.html`, `style.css`, `main.js` — the app (MapLibre GL JS from CDN,
  no build step).
- `data/*.geojson` — generated by `scripts/export_traces_web.py`:
  - `diy_villages.geojson` — simplified DIY village boundaries (context)
  - `traces.geojson` — one `LineString` per sampled device
  - `points.geojson` — one `Point` per ping (time + speed for popups)

## How to run
```powershell
# 1. (re)generate the data for another day / selection
python scripts/export_traces_web.py --day 2021-10-30 --n 8 --pick mix

# 2. serve — fetch() requires http://, not file://
python -m http.server 8000 --directory web
# open http://localhost:8000
```

## Features
- Village-boundary basemap + CARTO light tiles.
- **Toggle** each device on/off.
- **Solid lines** = movement between consecutive pings with short gaps;
  **dashed lines** = the jump between bursts (sampling gap > 30 min), with a
  **duration label** (e.g. `+3h 40m`) on long gaps — so sampling gaps read as
  time, not teleportation.
- **Click any ping** → popup with time, speed-to-previous, coordinates, and
  a "N pings here" burst summary when several pings share a spot.
- **Play / slider** animates a marker per visible device through its pings
  (the clock shows the current time).
- GPS-spike filter (120 km/h) is applied at export time.

## Notes
- Devices often look like "a few dots" — that's real: they sit in stationary
  bursts at a handful of locations, and the long dashed segments are the time
  gaps between bursts (see `FINDINGS.md` §8 on GPS outliers).
- Traces are **time-ordered**; use the slider/play to see the actual sequence.
- Export picks a "mix" of devices by default (1 long-distance + commuters +
  local) so a variety of movement is visible at once.
