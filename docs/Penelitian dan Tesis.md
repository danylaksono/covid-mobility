## Skripsi dan Tesis

Skripsi dan tesis mahasiswa memanfaatkan data mobility

- Pengembangan Teknologi Big Data untuk Analisis Mobile Positioning Data Menggunakan Apache Spark …
	Nurul Khairiza Utami
	Solusi yang dikembangkan mengintegrasikan Apache Spark dan Hadoop dengan orkestrasi kontainer Docker pada Docker Swarm di kluster penelitian yang terdiri dari tiga mesin …
- [Analisis Pola Agregat Mobilitas Manusia dengan Modified Standard Distance …](https://etd.repository.ugm.ac.id/penelitian/detail/225538)
	Sagara Aldavy
	Analisis mobilitas manusia dapat meningkatkan pemahaman akan bagaimana manusia berinteraksi dengan lokasi manusia berada. Dalam tugas akhir ini, digunakan *active mobile positioning data* yaitu GPS untuk menganalisis seberapa jauh deviasi manusia terhadap titik lokasi rumahnya menggunakan *modified standard distance …*
- [Identifikasi dan Analisis Mobilitas Wisatawan Menggunakan Metode Machine Learning …](https://etd.repository.ugm.ac.id/penelitian/detail/228173)
	Handoko WM
	Terdapat beberapa metode yang bisa digunakan untuk mengidentifikasi wisatawan, seperti metode rule-based, probabilistik, machine learning, ataupun deep learning. Penelitian ini berfokus pada identifikasi wisatawan menggunakan metode machine learning pada data MPD aktif..
- [Pengembangan Aplikasi People Mobility Analysis Berbasis Web Menggunakan Lokasi Telepon Seluler …](https://etd.repository.ugm.ac.id/penelitian/detail/214246)
	Salomo Hutapea
	Fitur utama dari aplikasi ini adalah dapat memetakan pergerakan suatu kelompok masyarakat dari satu tempat ke tempat lainnya dalam jangka waktu tertentu. Aplikasi yang dikembangkan berbasis web sehingga dapat diakses siapa saja yang memiliki otorisasi akses dengan internet browser …
- [Pengembangan Academic Sandbox Untuk Eksplorasi Mobilitas Manusia Berdasar Data Lokasi Telepon Seluler …](https://etd.repository.ugm.ac.id/penelitian/detail/213443)
	Syafaatul Khayati
	Seiring berkembangnya zaman, penggunaan perangkat seluler menghasilkan semakin banyak jenis data sebagai byproduct. Salah satu data tersebut adalah Mobile Positioning Data (MPD) yang merupakan estimasi lokasi berbasis Call Detail Records (CDR) yang dicatat penyedia jaringan seluler …
